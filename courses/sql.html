MODULE 01 FOUNDATIONS

Introduction to Databases and SQL

A database stores information in an organized way. In a relational database, information is commonly arranged in tables made up of rows and columns.

Think of a student table

Each row represents one student. Each column describes an attribute, such as the student's name or major.

student_id name major
101 Amira Software Engineering
102 Omar Computer Science
103 Sara Software Engineering

Your first SQL query

SQL stands for Structured Query Language. It lets you ask a database questions about the information it stores. 

SELECT name
FROM students;

This query asks the database to return the name column from the students table.

Remember

SELECT specifies what information you want. FROM specifies which table contains it.

MODULE 02 RETRIEVING DATA

SELECT Statements

The SELECT statement retrieves data from a table. You can request specific columns or all available columns.

Select specific columns

SELECT name, major
FROM students;

Only the name and major columns are returned.

Select every column

SELECT *
FROM students;

The asterisk (*) requests all columns. For everyday queries, selecting only the columns you need can make your intentions clearer.

Rename a result column

SELECT name AS student_name
FROM students;

The AS keyword gives the output column a more descriptive heading. It does not rename the original column.

MODULE 03 FILTERING DATA

Filtering with WHERE

A query without a filter can return many rows. Use WHERE to retrieve only records that match a condition.

Match a specific value

SELECT name, major
FROM students
WHERE major = 'Software Engineering';

Text values are usually enclosed in single quotation marks. This query returns students whose major matches the specified value.

Combine conditions

SELECT name, major
FROM students
WHERE major = 'Software Engineering'
  AND student_id > 101;

AND requires both conditions to be true. OR allows either condition to be true, while NOT negates a condition.

Useful operators

  • = equal to
  • > greater than
  • < less than
  • >= greater than or equal to
  • <> not equal to in standard SQL
A common mistake

Use IS NULL to test for missing values, not = NULL.

MODULE 04 ORDERING RESULTS

Sorting and Limiting Results

Use ORDER BY to arrange rows by one or more columns. Use LIMIT in SQLite and several other database systems to restrict the number of returned rows.

Sort from highest to lowest

SELECT name, score
FROM students
ORDER BY score DESC
LIMIT 5;

DESC sorts in descending order. ASC sorts in ascending order and is the default when no direction is specified.

Sort by multiple columns

SELECT name, major, score
FROM students
ORDER BY major ASC, score DESC;

This sorts by major first, then by score within each major.

Database differences

SQLite and MySQL support LIMIT. SQL Server commonly uses TOP or OFFSET ... FETCH, depending on the query.

MODULE 05 SUMMARIZING DATA

Aggregate Functions and GROUP BY

Aggregate functions calculate a summary from multiple rows. They are useful when you want totals, averages, counts, or minimum and maximum values.

Count students in each major

SELECT major, COUNT(*) AS student_count
FROM students
GROUP BY major;

Common aggregate functions

  • COUNT() counts rows or non-NULL values.
  • SUM() adds numeric values.
  • AVG() calculates an average.
  • MIN() returns the minimum value.
  • MAX() returns the maximum value.

Filter groups with HAVING

SELECT major, COUNT(*) AS student_count
FROM students
GROUP BY major
HAVING COUNT(*) > 1;

GROUP BY creates groups. HAVING filters those groups after aggregation, while WHERE filters individual rows before grouping.

MODULE 06 RELATING DATA

Joining Tables

Relational databases often store related information in separate tables. A JOIN combines rows from those tables using a related column or condition.

Understand the relationship

Imagine that the students table stores student details and the enrollments table stores the courses each student takes.

A primary key identifies a row in its table. A foreign key refers to a related row in another table.

Join students to enrollments

SELECT students.name, enrollments.course_id
FROM students
JOIN enrollments
  ON students.id = enrollments.student_id;

The ON condition tells the database how the rows relate. An inner JOIN returns matching rows; a LEFT JOIN also keeps unmatched rows from the left table.
